I run **RAD LAB**, a one-person shop in Italy 🇮🇹 that automates the boring parts of running a local business.

Restaurants, hotels, salons and medical practices share one problem: the phone rings while your hands are full. So I make WhatsApp answer for them. Bookings, confirmations, reminders, review follow-ups. No conversational AI talking to real customers, just fixed workflows that do the same thing every time.

Before this I stacked shelves, waited tables and drove a delivery van. I know these businesses from the inside, not from a slide deck.

### What I'm building

**[MenuLampo](https://menulampo.it)** QR menus for restaurants that update in seconds from a WhatsApp message. Seven languages, allergens, live sync, nothing for the guest to install.

**[RAD LAB](https://radlab.it)** the shop itself: automation, software and websites for local businesses.

### Open source

**[n8n-hospitality-templates](https://github.com/riccardomrad/n8n-hospitality-templates)** the restaurant booking system I run in production, cleaned up and documented in English and Italian: create and confirm, handle the guest's reply, remind 24h before, catch the failures.
