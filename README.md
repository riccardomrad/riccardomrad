# Hi, I'm Riccardo 👋

I run **RAD LAB**, a one-person shop in Italy 🇮🇹 that automates the boring parts of running a local business.

Restaurants, hotels, salons and medical practices have the same problem: the phone rings while you have your hands full. So I make WhatsApp answer for them. Bookings, confirmations, reminders, review follow-ups. No conversational AI talking to real customers, just fixed, predictable workflows that do the same thing every time.

Before this I stacked shelves, waited tables and drove a delivery van. I know these businesses from the inside, not from a slide deck.

## What you'll find here

Everything I publish is code that already runs in production for paying clients, cleaned up and documented in English.
